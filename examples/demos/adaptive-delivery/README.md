# Adaptive Delivery example

This directory contains synthetic, network-free evidence and a two-slot sandbox
for the guided Adaptive Delivery demo. It does not contain a live selection,
credential, receipt, approval, or deployment.

The selectable discovery and implementation agents return target-free advisory
content. Trusted code alone maps `delivery-source` and `delivery-test` to the
example paths after an accepted plan and exact signed stage-selection grant.
