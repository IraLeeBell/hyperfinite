# Demo Project seed examples

Each subdirectory contains one synthetic seeded issue/card representation for
the corresponding declarative Project schema:

- `app-modernization/`
- `feature-delivery/`
- `security-dependency-remediation/`
- `adaptive-delivery/`

These files demonstrate the fourteen display projections only. Requested Stage
Agent remains a separate untrusted input field. Node IDs, field IDs,
option IDs, repository hints, and projected values are not trusted bindings or
transition authority. Use the
[Project setup runbook](../../docs/runbooks/github-project-setup.md) with fresh
authenticated exports for any human-admin sandbox planning.
