# Threat-to-control matrix

## Status

The matrix is **current for the governed architecture**. The repository provides
hermetic enforcement for exact target slots, complete TCB denial, signed
cross-phase cost accounting, ordinal delivery effects, comment-only review,
independent human-merge observation, deterministic closure, audit/metric/budget
evidence, and durable grant-claim boundaries. No row is fully deployed
under the readiness rule below because a secure App, state publisher, trusted
executor/bridge, OIDC redeemer, key custody, authenticated conditional evidence
store, serialization, administrator configuration, billing, platform
protections, and security-owner review remain human/deployment prerequisites.

## Readiness rule

A row moves from `planned` to `implemented` only when:

1. enforcement code is merged;
2. positive and negative tests cover every named path;
3. evidence is emitted and replayable;
