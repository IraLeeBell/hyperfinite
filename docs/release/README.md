# Release evidence

- [Deterministic local release evidence](local-release-evidence.md) documents
  archive construction and independent byte verification.
- [Release-candidate no-go checklist](release-candidate-checklist.md) defines
  the human evidence required before any release decision.
- [Customer-starter and open-source preflight](customer-starter-preflight.md)
  documents the configurable, mechanically-closed starter bundle and its
  non-authoritative preflight report.

Local archives, SBOMs, provenance statements, and checklists are unsigned
evidence. They are not a signature, publication authorization, license decision,
or readiness claim. This repository does not publish or deploy releases.
