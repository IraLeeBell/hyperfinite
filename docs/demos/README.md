# Governed demo portfolio

The portfolio is a disabled-by-default, hermetic-first demonstration of four
GitHub-native journeys:

| Demo | Stages | Model stages | Guide |
|---|---:|---:|---|
| App Modernization | 10 | 5 | [App Modernization](app-modernization/README.md) |
| Feature Delivery | 9 | 5 | [Feature Delivery](feature-delivery/README.md) |
| Security and Dependency Remediation | 9 | 5 | [Security and Dependency Remediation](security-dependency-remediation/README.md) |
| Adaptive Delivery | 9 | 5 stages / 8 candidates | [Adaptive Delivery](adaptive-delivery/README.md) |

Every fixed model stage has one globally exclusive agent, skill, capability,
and workflow identity. Adaptive Delivery has two prescribed selectable stages
that deterministically narrow to one exact candidate. Deterministic, planning,
Kernel, human-review, and terminal stages have no model agent. All journeys stop
at Human Review in hands-off simulation; Completed requires a separate
synthetic-human continuation.
