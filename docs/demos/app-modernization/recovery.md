# App Modernization recovery

Pause and block preserve the canonical stage cursor. Resume preserves it. A
nonterminal blocked recovery or retry advances authority generation and run
attempt exactly once; cancellation is terminal. Verification repair truncates
from Implementation, replan truncates from Migration plan, and requested
revision truncates from Implementation.

Partial effects, ambiguous persistence, and lost acknowledgements enter typed
reconciliation. Never retry blindly. Accept a lost Project acknowledgement only
after two stable exact reads. Persist and reread the applied Kernel result before
the stage receipt and Run State, then converge projections with Stage last.

Authorization invalidation returns to Activation pending. Reissue authority only
from current human-approved contracts and authenticated evidence. Preserve all
receipts, artifacts, budget records, and predecessor heads.
