# Adaptive Delivery

Adaptive Delivery is the fourth disabled-by-default, hermetic-first Hyperfinite
demo. Its guided posture demonstrates fixed agents and prescribed human choice
without moving authority into GitHub Projects or model output.

## Journey

| Stage | Execution | Participation |
|---|---|---|
| Intake | Deterministic | none |
| Context inventory - autonomous | Framing | fixed |
| Discovery studio - choose agent | Framing | three selectable candidates |
| Guided synthesis - autonomous | Framing | fixed |
| Implementation plan - deterministic gate | Planning | none |
| Implementation studio - choose agent | Execution | two selectable candidates |
| Test and verification - autonomous | Verification | fixed, exact-head, COMMENT-only |
| Human review | Human | none |
| Completed | Terminal | none |

Activation Pending, Paused, Blocked, and Cancelled remain Kernel-controlled
conditions.

## Selection boundary

Requested Stage Agent contains all five reviewed options because GitHub Projects
cannot conditionally filter a picklist by board column. Discovery options are
invalid during implementation and implementation options are invalid during
discovery. `resolveStageAgentSelection()` validates current human authorization,
the exact Project item, enterprise and project policy, Work Accord, Phase
Contract, stage option set, Capability Registry, Activation Lease, budget,
run/attempt/generation, receipt head, and current PR head before signing one
exact-agent grant.

Missing or invalid selection invokes nothing. There is no default or fallback.
A changed picklist cannot retarget an accepted dispatch. Direct invocation of a
selectable profile without signed stage context returns activation-required
advisory output that cannot advance the journey or satisfy a gate.

## Project fields

The customer Project is selected only through the independently confirmed target
manifest described in `docs/runbooks/github-project-setup.md`. Journey Stage,
Stage Interaction, Current Stage Agent, and Agent Selection Status are
projections.
Requested Stage Agent is untrusted input. Cards prefixed with
`[Synthetic display only]` are visual fixtures, not runtime state, receipts,
signatures, approvals, or authority.

Use the [Project setup runbook](../../runbooks/github-project-setup.md) for
plan/confirm/apply/readback and reset procedures. Runtime activation, paid
inference, App credentials, approval, merge, deployment, and publication remain
blocked.
