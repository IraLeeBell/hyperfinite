# Governance

- [Repository governance](../../GOVERNANCE.md) defines human decision rights,
  exact-head merge evidence, and actions automation cannot perform.
- [Capability lifecycle](capability-lifecycle.md) defines review, versioning,
  deprecation, disablement, and removal requirements for deny-by-default
  capabilities.
- [Open-source readiness](open-source-readiness.md) records the current
  `not-ready` decision and the human evidence required before publication.

Repository validation cannot make a legal, licensing, visibility, publication,
or production-readiness decision. Those decisions remain with authorized human
owners.
